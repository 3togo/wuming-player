## Purpose

Describe the problem, intended user value, and why retaining this code is useful.

## Limitations and risks

List incomplete behavior, unsupported platforms, security assumptions, licensing or provenance
questions, and unavailable dependencies.

## Dependencies and compatibility obligations

Record data formats, migrations, external systems, native binaries, or production behavior which
must be understood before deletion or restoration.

## Exit criteria

For incubating work, define the tests, review, platform support, and production integration needed
to graduate. For archived work, define when the directory can be deleted permanently.
