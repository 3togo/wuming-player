standalone license file. The author's repository supplies the full ISC text:
https://github.com/fb55/boolbase/blob/54811f01c797a6bb1c263183ae90b7dd627e0638/LICENSE

Package metadata: https://registry.npmjs.org/boolbase/1.0.0

archives by the build script. The lock records archive integrity checksums.
